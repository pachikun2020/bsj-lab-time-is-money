# Contributing

The first public release is being prepared. This project uses the MIT License. Please discuss substantial changes before submitting code.

- Use fictional meeting data in reports and screenshots. Never include secrets, real employee data or internal paths.
- Report vulnerabilities through SECURITY.md rather than a public Issue.
- Keep pull requests focused. Explain the user-visible change and how it was checked.
- UI changes must cover Japanese, English and Simplified Chinese, mobile and desktop, keyboard use and readable control sizes.
- Calculation changes must preserve country/currency separation and segment accounting. Default rates require an official source, year, occupation, unit and definition. Do not invent missing medians or full-time/part-time splits.
- Verify pause/resume, CSV and offline/cache behavior when affected. Include the test environment and any untested real-device behavior.
- Do not add analytics, external requests, dependencies, generated images or copied code without discussing their need and documenting their provenance and license.

Contributions are submitted under the MIT License, with the contributor confirming the right to contribute. No CLA or transfer of ownership is currently requested. Product names and logos must not imply endorsement of forks by MERYDS.
